# lsp

Language server clients. No drawing; the app (`app/lsp.rs`) owns a `Manager` and gets `Event`s as `AppEvent::Lsp`.

- `mod.rs` — `Manager`: `new(launcher)` (`None` = servers off: the test default), `start(sink)` (from `App::start`; nothing is spawned before), `sync(root, languages, workspace config, trust)` (each language → `config::resolve`; servers are shared by equal `ServerConfig`s (C and C++ share clangd); a server whose languages no longer resolve to it is sent `Shutdown` and kept in `stopping` until quit; one in `State::Failed` stays, so it's never restarted), `handle(Event) -> Option<Notice>` (state changes; not found / spawn / initialize errors and crashes become one `Level::Error` notice each; `window/showMessage` by its type), `shutdown()` (a `'static` future: `Shutdown` to all, waits `SHUTDOWN_TIMEOUT` + `ABORT_MARGIN` (1 s), then aborts — `kill_on_drop` kills the process; `shutdown_within(limit)` is the same with any limit and says whether every task ended by itself, which tests check instead of timing against the margin), `server_for(language)`, `servers()`, `publish(server, Published, buffers)` (see `diagnostics.rs`), `load_diagnostics(buffer)` (`App::add_buffer`: the stored ones placed in a newly opened buffer, read in its text), `take_cleared()` (servers whose diagnostics were dropped — stopped by `sync`, `Failed`, `Exited` — for the app to clear from buffers), `diagnostics` (the `Store`), `request_at(buffers, buffer, pos, method, supported, extra) -> Option<Sent { server, id, encoding }>` (`sync_documents` first, then `textDocument` + `position` (+ `extra`'s fields) to the server that has the buffer's document open (`Documents::document(buffer)` → server, URI, version), if `Running` and `supported(&capabilities)`), `cancel(server, id)` (`$/cancelRequest`; a later answer is dropped as nobody's), `server_of(buffer)` (the running server with the buffer's document: id, encoding, capabilities), `request(server, method, params)` (params as given, to a running server: `completionItem/resolve`). The app keeps what it waits for (`app/lsp.rs`). `Server` (`config`, `root`, `languages`, `state`: `Starting` / `Running { encoding, capabilities }` / `Failed`; `encoding()`, `request(method, params) -> id` (answer: `Event::Response` with that id; none once the server failed or exited — callers drop what they wait for on `Failed` / `Exited`), `notify(method, params)`). `Event`: `Initialized`, `Failed { StartError }`, `Exited { crashed }`, `Diagnostics { published }` (read in the server task: tens of thousands take tens of ms), `Notification` (anything the task doesn't handle itself), `Response`. `Sink` = `Arc<dyn Fn(Event) + Send + Sync>`.
- `server.rs` — `Launcher` (`launch(config, root) -> Transport { reader, writer, stderr, child }`; called in the server's task on a runtime worker): `ProcessLauncher` (`tokio::process`, cwd = root, piped stdio, `kill_on_drop`; a bare command is looked up on `PATH`, a relative path with a `/` is relative to the root). `Task::run`: launch (`NotFound` → `StartError::NotFound`), a separate writer task (no stdin/stdout pipe deadlock), `initialize` (`processId`, `rootUri` + `workspaceFolders`, `clientInfo`, `initializationOptions`, `general.positionEncodings: [utf-8, utf-16]` and clangd's older `offsetEncoding`), then one `select!` over stdout (`rpc::Framer`), stderr lines, app commands (`ToServer::{Request, Notify, Shutdown}`) and the shutdown deadline. Client capabilities: `textDocument.hover.contentFormat` (markdown, plain text), `textDocument.definition.linkSupport`, `textDocument.completion` (commit characters, preselect, insert/replace edits, label details, resolve of detail / documentation / additionalTextEdits, `contextSupport`, `itemDefaults`; no `snippetSupport`: no snippet session), `textDocument.publishDiagnostics.versionSupport` (no pull `textDocument.diagnostic`: ty and clangd push without it). `Conn` is the protocol state: pending ids (`Initialize`, `Shutdown`, `App`), the app's messages queued until `initialize` is answered (then `initialized`), server requests answered minimally (`workspace/configuration` → a `null` per item, `workspaceFolders`, progress create / (un)registerCapability / refreshes → `null`, `applyEdit` → not applied, else MethodNotFound), `window/logMessage` logged, `$/progress` dropped. Encoding: `utf-8` if the server chose it (`capabilities.positionEncoding` or `offsetEncoding`), else UTF-16. `Shutdown`: `shutdown` request → `exit` on its answer; before `initialize` returns it just stops; after `SHUTDOWN_TIMEOUT` (1.5 s) the process is killed, and once `exit` is out it gets `EXIT_GRACE` (300 ms) to close its output before it's killed (clangd with a file open keeps indexing the standard library for ~2 s after `exit`). On the way out the child is waited for 500 ms (not after a timeout), then killed. A protocol error or EOF that wasn't asked for is a crash (`Exited { crashed: Some(why) }`, the exit status appended, the last 20 stderr lines logged at warn).
- `rpc.rs` — `Message::{Request, Response, Notification}` (`from_value` / `to_value`; `Id::{Num, Str}`: a server's string ids are echoed back), `RpcError`, `encode_body`, `Framer` (`push` bytes, `next()` complete bodies; `Content-Length` required, other headers ignored, names case-insensitive; `FrameError` for a missing / bad length, a bad header line, an 8 KB header without a blank line, a body over 256 MB — the connection is then dropped).
- `config.rs` — `ServerConfig { name (the command's file name), command, args, init_options (JSON), from_workspace }`, `Builtins` (`clangd`; `ty` with `server`; tests replace them), `resolve(language, workspace, trust, builtins) -> Resolved::{Server, AwaitingTrust, None}`: `.workspace` `[lsp.<Language::id>]` when `Trusted`, nothing while `Undecided`, the built-in when restricted (PLAN: servers from global config still run).
- `documents.rs` — document sync. `Documents` (on the `Manager`: `sync_documents(buffers)` each loop turn, `saved(buffers, id)`, `version(id)`): a buffer with an absolute path whose language's server is `Running` and wants open / close gets `didOpen` (`languageId` = `Language::id()`, version 1, the text) and `track_changes(true)`; each turn its `take_tracked()` sets go out as one `didChange` (version + 1) — `Incremental`: `content_changes` (each set's changes last first, so all ranges stay in its pre-edit coordinates; changes that touch are merged into one, else a later one could make a lone CR before an earlier one's end a CRLF; a set over `COALESCE_AT` (256) changes is one range from its first change to its last, with that stretch of the text after it; positions through one `pos::LspWalker` per set), `Full`: the whole text, `None`: nothing. A changed path (rename) / language / server closes (`didClose`) and reopens it; a closed buffer gets `didClose`; a server that stopped or failed has its documents forgotten silently. `didSave` after a save (changes sent first; `text` when `includeText`). `SyncOptions::of(caps)`: a bare kind = open / close + that change kind + save without text (VS Code's reading); options as given; missing = nothing. Requests about a document (9c on) must follow the turn's `didChange`: call `sync_documents` first. Each document keeps its last `KEEP_VERSIONS` (32) versions as sent (text: a cheap rope clone, and the change sets to the next version; nothing for a server without change sync); `since(buffer, server, version)` gives a version's text and the sets since, dropping older versions (servers publish in order).
- `diagnostics.rs` — `parse(params) -> Published { path, version, items: Vec<Item { start, end: LspPos, diag: Arc<Diagnostic> }> }` (sorted by start; a reversed range is empty; missing severity = error), `resolve(server, items, text, encoding, since)` → `diagnostics::Mark`s (positions by one `pos::LspReader` pass in `text`, then mapped through `since`), `Store` (path → per-server `FileSet { server, encoding, items }`, a `BTreeMap` so `files()` is sorted for the Problems list; `publish` replaces one server's set, empty removes it; `clear_server`; `get(path)`; `counts()` kept incrementally, `Counts::of(severity)`). `Manager::publish`: drops a publish from a server that isn't `Running`; if a buffer has the path, `sync_documents` first (this turn's edits become a version), then `Documents::since(version)` → read in that text and mapped forward, else (no version, not kept, another server's document) read in the current text; the buffer's marks for that server replaced; then stored. Closed files keep their diagnostics (as VS Code); a server's are all dropped when it stops.
- `uri.rs` — `from_path` (percent-encodes everything but unreserved chars and `/`), `to_path`.
- `fake.rs` (`cfg(test)`) — `FakeLauncher::new(FakeOptions { utf8, missing, crash_after_init, ignore_shutdown, init_error, sync })`: each launch runs an in-process server over a `tokio::io::duplex` that records what it receives and keeps its own copy of each open document (`didChange` ranges applied with its own position code, not `buffer::pos`; `document(uri)`, `saves()`, `errors()` for bad versions / ranges / a `didSave` text that isn't its copy); the module doc lists its test methods (`test/echo`, `test/later` + `test/flush` for out-of-order answers, `test/publish` (sends `publishDiagnostics` with its params), `test/crash` (hangs up)); it advertises `hoverProvider` / `definitionProvider` / `completionProvider` (trigger characters `.` and `>`, `resolveProvider`; an unscripted `completionItem/resolve` answers with the item it got); `respond(method, result)` scripts the answer to every `method` request, `hold(method, on)` keeps them until `test/flush`, a `$/cancelRequest` for a held one answers it with -32800; `requests(method)` (their params), `cancelled()` (ids).
- Logging: `target: "lsp::wire"` at trace (every message, `→` out / `←` in, with `server`), `target: "lsp::stderr"` at debug; the rest under `red::lsp` (start / initialized / stopped at info).
