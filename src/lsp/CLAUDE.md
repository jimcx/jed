# lsp

Language server clients. No drawing; the app (`app/lsp.rs`) owns a `Manager` and gets `Event`s as `AppEvent::Lsp`.

- `mod.rs` — `Manager`: `new(launcher)` (`None` = servers off: the test default), `start(sink)` (from `App::start`; nothing is spawned before), `sync(root, languages, workspace config, trust)` (each language → `config::resolve`; servers are shared by equal `ServerConfig`s (C and C++ share clangd); a server whose languages no longer resolve to it is sent `Shutdown` and kept in `stopping` until quit; one in `State::Failed` stays, so it's never restarted), `handle(Event) -> Option<Notice>` (state changes; not found / spawn / initialize errors and crashes become one `Level::Error` notice each; `window/showMessage` by its type), `shutdown()` (a `'static` future: `Shutdown` to all, waits `SHUTDOWN_TIMEOUT` + 1 s, then aborts — `kill_on_drop` kills the process), `server_for(language)`, `servers()`. `Server` (`config`, `root`, `languages`, `state`: `Starting` / `Running { encoding, capabilities }` / `Failed`; `encoding()`, `request(method, params) -> id` (answer: `Event::Response` with that id; none once the server failed or exited — callers drop what they wait for on `Failed` / `Exited`), `notify(method, params)`). `Event`: `Initialized`, `Failed { StartError }`, `Exited { crashed }`, `Notification` (anything the task doesn't handle itself), `Response`. `Sink` = `Arc<dyn Fn(Event) + Send + Sync>`.
- `server.rs` — `Launcher` (`launch(config, root) -> Transport { reader, writer, stderr, child }`; called in the server's task on a runtime worker): `ProcessLauncher` (`tokio::process`, cwd = root, piped stdio, `kill_on_drop`; a bare command is looked up on `PATH`, a relative path with a `/` is relative to the root). `Task::run`: launch (`NotFound` → `StartError::NotFound`), a separate writer task (no stdin/stdout pipe deadlock), `initialize` (`processId`, `rootUri` + `workspaceFolders`, `clientInfo`, `initializationOptions`, `general.positionEncodings: [utf-8, utf-16]` and clangd's older `offsetEncoding`), then one `select!` over stdout (`rpc::Framer`), stderr lines, app commands (`ToServer::{Request, Notify, Shutdown}`) and the shutdown deadline. `Conn` is the protocol state: pending ids (`Initialize`, `Shutdown`, `App`), the app's messages queued until `initialize` is answered (then `initialized`), server requests answered minimally (`workspace/configuration` → a `null` per item, `workspaceFolders`, progress create / (un)registerCapability / refreshes → `null`, `applyEdit` → not applied, else MethodNotFound), `window/logMessage` logged, `$/progress` dropped. Encoding: `utf-8` if the server chose it (`capabilities.positionEncoding` or `offsetEncoding`), else UTF-16. `Shutdown`: `shutdown` request → `exit` on its answer; before `initialize` returns it just stops; after `SHUTDOWN_TIMEOUT` (1.5 s) the process is killed. On the way out the child is waited for 500 ms, then killed. A protocol error or EOF that wasn't asked for is a crash (`Exited { crashed: Some(why) }`, the exit status appended, the last 20 stderr lines logged at warn).
- `rpc.rs` — `Message::{Request, Response, Notification}` (`from_value` / `to_value`; `Id::{Num, Str}`: a server's string ids are echoed back), `RpcError`, `encode_body`, `Framer` (`push` bytes, `next()` complete bodies; `Content-Length` required, other headers ignored, names case-insensitive; `FrameError` for a missing / bad length, a bad header line, an 8 KB header without a blank line, a body over 256 MB — the connection is then dropped).
- `config.rs` — `ServerConfig { name (the command's file name), command, args, init_options (JSON), from_workspace }`, `Builtins` (`clangd`; `ty` with `server`; tests replace them), `resolve(language, workspace, trust, builtins) -> Resolved::{Server, AwaitingTrust, None}`: `.workspace` `[lsp.<Language::id>]` when `Trusted`, nothing while `Undecided`, the built-in when restricted (PLAN: servers from global config still run).
- `uri.rs` — `from_path` (percent-encodes everything but unreserved chars and `/`), `to_path`.
- `fake.rs` (`cfg(test)`) — `FakeLauncher::new(FakeOptions { utf8, missing, crash_after_init, ignore_shutdown, init_error })`: each launch runs an in-process server over a `tokio::io::duplex` that records what it receives; the module doc lists its test methods (`test/echo`, `test/later` + `test/flush` for out-of-order answers).
- Logging: `target: "lsp::wire"` at trace (every message, `→` out / `←` in, with `server`), `target: "lsp::stderr"` at debug; the rest under `red::lsp` (start / initialized / stopped at info).
