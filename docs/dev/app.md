# app submodules (detail)

Every `src/app/` submodule in full: its state, functions, events and rules. `src/app/CLAUDE.md` has one line each plus the things to know before editing; read the entries here for the submodules you touch.

`App` (in `mod.rs`) owns all state; submodules are `impl App` blocks split by area, with `pub(super)` methods:

- `mod.rs` — struct, `new`/`start`/`run`, `handle_event`, `execute`, `sync_views`, copy/paste (paste looks up `clipboard.copied(text)` for the whole-line flag and per-selection pieces), `handle_app_event`, crash snapshots, and the `#[cfg(test)]` driving helpers (`test_start`, `test_plain_whitespace` (whitespace drawn as blanks via the session toggle, for tests reading drawn text with spaces), `test_open` (a buffer in a new tab), `test_execute(cmd)` (a command as its key would run it), `press`, `press_file_start` / `press_file_end` (Cmd+Up / Down on macOS, Ctrl+Home / End on Linux), `type_text`, `mouse`, `mouse_with`, `handle_test_event`, `settle`, `pump` (queued `AppEvent`s, no waiting, then `sync_syntax`), `test_search_batch`, `test_lsp_event` (a language server event handled before the turn's `sync_servers`), `test_hover_tick(now)` (the hover rest timer), `test_completion_tick(now)` (the quick-suggestion timer), `test_backup_tick(after)` (the backup timer `after` from now, after a `sync_backups`), `test_panic_backup()` (the panic hook's backup of the crash snapshot), `test_locations_read(generation, files)` (an `AppEvent::LocationsRead` as the background read sends it), `test_git_history_page(path, skip, generation, result)` (a page of a file's commits as `AppEvent::GitHistory` sends it), `pending_requests()` (kind, position), `quitting`, the `last_command` field). `sync_views` = `follow_edits` (every other view on an edited buffer maps through its applied sets; also called directly after edits made by background results) + `track_selections`. `render_whitespace()`: the `render_whitespace` setting, or after "View: Toggle Render Whitespace" (`ui.whitespace_toggled`, session-only, never written to a file, kept across `.workspace` reloads) `none` — or the setting again (`all` when it is `none`); `ui::render` passes it to the editor in `Overlay::whitespace`. `sync_cursor_shape(out)` (each `run` turn, after the pointer): sends `terminal::CursorShape::of(&settings)` when it differs from `cursor_shape`, the one last sent (`terminal::enter` sent the start's) — a `.workspace` reload changing `cursor_style` / `cursor_blinking`.
- `mode.rs` — `Mode::{Workspace, SingleFile}` (`app.mode`, set by `main` through `App::new_in`; `App::new` is `new_in(Mode::Workspace, …)`, tests only) and the one availability answer `Mode::allows(cmd)` / `allows_view(panel)`: in single file mode the side views, bottom panel, quick open (the palette's file mode shows the notice), workspace search, tasks, trust, recent workspaces, server / tool-trace commands, file history and git (stage / unstage, Open Changes, blame) are off — `execute` notifies `UNAVAILABLE` ("Not available in single file mode"), the palette leaves them out, the activity bar greys their icons (`activityBar.disabled`) and their clicks do nothing. Single file mode also: starts with the side panel hidden and asks no trust (no Restricted badge); `start_single` only watches the file (`watcher::start_file`), scans backups (offering only the file's) and parses — no servers, tasks, git status (`refresh_git` returns: no branch, gutter markers or blame), session read / write (`save_session` returns), recent entry, listings (`request_listing` / `reveal_active` return) or file history (`history_job`); no live `.workspace` reload; `discard_tab` quits (`request_quit`) once no tab is left; the status bar shows " Single file " (or `app.editor_hint`, set by `main` for git message files: see `git_editor.rs`) where the branch goes.
- `files.rs` — `new_untitled_file` ("File: New Untitled File", Cmd+N: `Buffer::untitled(buffers.free_untitled_number())` in a new tab; `save` on an untitled buffer opens the Save As prompt), open (off-thread `Buffer::open` → `AppEvent::Opened { path, result }`, the buffer boxed; `open_file(path, focus, goto)` (sets `nav_jump`) opens in the active group, or applies `goto` at once when the buffer is already loaded; the in-flight `opening` map holds each path's `OpenRequest { focus, goto, background, edits, restore, backup }`, a repeat request replacing its `goto` (the last F4 wins), adding focus and clearing `background`, and `opened` takes it back (a path loaded meanwhile — a session's restore — keeps that buffer: the loaded one is dropped and the request goes to `open_file`): a `background` one (a rename's file) goes in a tab beside the active one (`Group::open_background`), then its `edits` are applied (`apply_pending_edits`), then a `restore` (a file history entry: `restore_history`), then a `backup` (a crash backup: `restore_backup`; a failed load keeps it: `backup_not_opened`); a failed load with edits says "Rename not applied to …"), `Goto` (`Cursor(line, col)`: 1-based line and display column — `file:line:col`, `InitialFile`; `Match { line, range }`: a search result, 0-based line + byte offsets, selected anchor→head and centred via `reveal_range`, clamped to the line count, the line's end and char boundaries since the text may have changed; `Place(navigation::Pos)`: Go Back / Forward's selection and scroll (`navigation::place_view`); `Problem { place, select }`: a `problems::Place` — byte range in the open buffer (clamped) or LSP positions read with `pos::from_lsp_pos` — selected, or a cursor at its start, centred via `reveal_range`), `apply_goto`, `add_buffer` (= `register_buffer`: language, stored diagnostics, the first view — then a tab), `place_cursor` (1-based line/column, clamped), tab activation/cycling, `focus_group`, `split`, `move_tab_to_group(forward)` (seals undo, `Groups::move_active_tab`, focuses the editor) / `move_tab(±1)` (`Group::move_active`), `close_tab`/`discard_tab`, save/`save_done` (the save's task runs `SaveJob::write`, sends `SaveDone`, then records the file history snapshot when `history_job` gave one; `SaveError::Conflict`: nothing written, a disk check shows the banner, a pending close / quit stops; every end of a save runs `disk_save_done`), quit. **Save As** (`open_save_as` opens `InputKind::SaveAs { buffer }`, prefilled and selected with the path relative to the root, an untitled buffer's name; `save_as_target` resolves it against the root (`.` / `..` lexically) and refuses empty names, a trailing `/` and a path open in another buffer; `save_as_to` runs `Buffer::begin_save_as` through `spawn_save` (shared with `save`), `SaveDone.to` carrying the new path): the write job (no stat on the UI thread) answers `SaveError::Exists` → `Prompt::ConfirmOverwrite`, `Failed` (a folder, a missing parent) → the prompt again with an error; on success `finish_save_as` sets the path, the language is re-detected (a picked one stays) and `servers_dirty` set. Esc on either prompt calls `cancel_save_as` (clears `after_save` and `save_as_queue`). Save All and the quit prompt's Save go through `save_batch`: files at once, untitled buffers queued in `save_as_queue` and prompted one after another (`next_save_as`); a pending `AfterSave::Quit` waits for the queue and the open prompt. `active_savable_buffer` is Save / Save As's target. Save As is off in single file mode, Save All isn't.
- `field.rs` — `field_key(field, own, key) -> Outcome`, used by `find_key`, `search_key`, `palette_key` and the `Input` prompt: a plain char is typed (`TextField::key`); else the command the field's own context `own` binds to the key when it `has_field_meaning`, else the key's `Context::Editor` command (globals included); `FieldCommand::from_command`'s run on the field (`TextField::run`), `Copy` / `Cut` write the selected text to `app.clipboard` (nothing without a selection), `Paste` (Linux Ctrl+V) inserts `read_clipboard()` without line breaks (a message when unreadable); anything else does nothing. `handle_event` doesn't `execute` a field-meaning command while `field_focused()` (palette open, `Focus::Find`, the Search view's input — not its list): it goes to the field, so a global `keybindings.toml` binding of an editor command applies in fields, not to the editor behind them. Bracketed pastes (`*_paste`) `insert`, replacing the selection.
- `prompt.rs` — `Prompt` (modal: `SaveBeforeClose`, `SaveAllBeforeQuit`, `Trust`, `Input`, `ConfirmDelete`, `SaveBeforeStage { buffer, line, file }` (staging from a dirty buffer — a change, or with `file` the whole file: Save and Stage / Cancel), `SaveBeforeStageAll { buffers }` (Stage All with dirty buffers among its files: Save and Stage → `save_then_stage_all`), `RestoreBackups` (the start's crash backups: R / Enter → `restore_backups`, D → `discard_backups`, L / Esc → `keep_backups`), `ConfirmOverwrite { buffer, path }` (Save As onto an existing file), `ConfirmReplace { occurrences, files, with }` (the Search view's Replace All over more than one file: R / Enter → `replace_now(Scope::All)`, C / Esc cancel)), `Input` (a `field::TextField` plus what the name is for: `InputKind::{NewFile, NewFolder, Rename, SaveAs, RenameSymbol}` — `SaveAs` is submitted to `save_as_target` (paths may be nested or absolute); the last is F2's new name, submitted to `request_rename` unless empty or unchanged, no file-name validation), `handle_prompt_key`, trust decisions (the `Trust` dialog also shows the current decision when reopened by "Manage Workspace Trust").
- `side.rs` — explorer commands, directory listings, file ops (`FileOp` → `AppEvent::FileOpDone`; a rename also moves file history: `history_rename`), fs-change batching (`flush_fs_changes` (paths under `.jed/` never get here: `fs_changed`): listings, `git_paths_changed`, `disk_paths_changed`, `diffs_paths_changed`), `.workspace` reload (`config_loaded`: `self.settings = self.workspace.settings()`, so the user's `settings.toml` stays layered underneath).
- `navigation.rs` — back / forward (`app.nav`, a `NavState`: `history` (`navigation::History`), the event's `jump` / `navigating` flags, `pending` (a file Go Back is reopening)): `nav_begin` / `nav_end(before, input)` (around every `handle_event`, `handle_app_event` — not `SessionRead` — and `test_execute`; see the root CLAUDE.md's invariant), `nav_jump`, `navigate(dir)` (`nav.back` / `nav.forward`: the entry's group, else the active one; a text tab of its file (a diff or hex tab for a path-only entry, any counts; `here()` gives a hex tab's path only, as a diff's), else a new view of its loaded buffer, else (no buffer) another group's hex tab of it (`show_hex`), else `open_file(path, true, Goto::Place)` with `pending`), `nav_opened` (top of `files::opened`: the pending file arrived — gone from disk (no `disk()` stamp) or failed, and nothing else wanted it → dropped, its entry `skip`ped, navigation goes on), `place_view` (selection + scroll clamped to the text, cursor revealed).
- `palette.rs` — `open_palette(picker, text)` / `close_palette` (also drops `file_history.picker` and `recent.picker`), `palette_command` (`PaletteCommand`), `palette_key` / `palette_paste` (input → `refresh_palette`), `accept_palette` (run a command, open a file at `file:line:col`, go to line, set a log level, a history entry → `history_picked`, a recent workspace → `open_recent`, a tool → `open_tool_log`), `palette_mouse`; quick open's walk (`start_file_walk`, once per opening, into `FileMatcher`) and `files_matched` / `files_walked`; the palette-only commands: `manage_trust`, `open_log_file` (→ `AppEvent::LogFileFound`), `open_user_settings` (`config::settings::create_if_missing` off-thread → `AppEvent::UserSettingsReady` → opens it), `set_log_filter`.
- `cheatsheet.rs` — the keyboard cheat sheet overlay (`app.cheat_sheet`, model `crate::cheatsheet`): `toggle_cheat_sheet` (`Command::CheatSheet`, `help.cheatSheet`, Shift+F1; records `context()` for the first section; from the palette, `execute` has closed it first), `cheat_sheet_key` (from `handle_event` right after a prompt: Esc or whatever key looks up to `CheatSheet` closes it; plain Up / Down / PageUp / PageDown / Home / End scroll; every other key swallowed — paste too), `cheat_sheet_mouse` (every mouse event while open, a prompt first: the wheel scrolls it anywhere, a press outside `HitMap::cheat_sheet`'s rect closes it and does nothing else, its bar clicks / drags / hovers through `app/scrollbar.rs` under `ScrollTarget::CheatSheet`). The terminal cursor is hidden while it's open.
- `cursors.rs` — `match_command` (Cmd+D / Cmd+Shift+L / Cmd+Alt+D through `multicursor`, keeping the `MatchSession` with the view — group, tab, buffer — it belongs to), `cursor_undo` (Cmd+U: pops `view.cursor_history`, restores selections and scroll), `note_pre_event` (start of `handle_event`: scroll before the event, for the Cmd+U entry) and `track_selections` (end of `sync_views`; also `view.auto_closed.validate`, so auto-closed pairs end once the cursors leave them, as VS Code checks on every selection change).
- `find.rs` — the find / replace widget (`app.find`, a `find::FindWidget`): `open_find(replace)` (seeds from a one-line selection or the word under an empty cursor, escaped when regex is on, selects the query, selects its match; with replace and a query the replace input gets the cursor), `close_find`, `find_command` (`FindCommand`), `find_key` / `find_paste` (edits the focused input; edits to the query `research`: re-search and select the first match from the primary's start), `refresh_find` (after every event: re-searches only when buffer/revision/query/options changed; closes the widget when there's no tab), next / previous via `Matcher::find_next` / `find_prev` with wrap, toggles (flip `find_options`, end a non-word-mode Cmd+D session via `find_options_changed`, say so in the status bar when the widget is closed), Alt+Enter (every match a selection, focus to the editor), replace one (`EditKind::Other`, then next) and replace all (one `ChangeSet` built with `push` — straight from the cached matches when the replacement names no group — one `Buffer::edit`, selections mapped through it), `find_mouse` (clicks on toggles / inputs, from `hits.find`). On a hex tab (`active_hex()`) the same entry points search bytes: `open_hex_find` (seeds from a selection of ≤ `HEX_SEED_MAX` (256) bytes in the current mode — hex pairs, or the text when printable — else the last query; Cmd+Alt+F opens it without replace), `refresh_hex_find` (`HexFind::refresh`; a new query's count runs in `spawn_blocking` (`hex::count` up to `HEX_MAX_COUNT`) → `AppEvent::HexCount { tab, generation, count }` → `hex_counted`, stale ones dropped; the field is forced to Find), `hex_find_from(from, forward)` (incremental search from the selection's start or the cursor; next from the selection's start + 1 so overlapping matches each get a step, previous before its start; `HexTab::select`), `toggle_find_hex` (`find.toggleHex`, Cmd+Alt+X / Alt+X or a click on `0x`: flips `find_options.hex` and converts the query with `hex::convert`; inert on a text tab, which draws no `0x`); whole word / regex toggles, Alt+Enter, replace and Tab do nothing there, Cmd+D neither (no text tab).
- `workspace_search.rs` — the Search view (`app.search_view`, a `search_view::SearchView`): `search_focused` (focus `SidePanel` with `ui.side_panel == Search`: the query or the results list has the keys), `find_in_files` (Cmd+Shift+F: show the view, seed from a non-empty one-line primary selection, regex-escaped when its regex is on, select the query, search at once), `replace_in_files` (`ReplaceInFiles`, Cmd+Shift+H, global: `find_in_files`'s seeding, the replace input shown and given the keys, its text selected — the query instead while it's empty, VS Code's), `search_command` (`SearchCommand`: toggles flip the view's own options and search at once; `ToggleReplace` (the `▸` toggle, palette: `SearchView::toggle_replace`, focusing the view first from elsewhere); `ToggleDetails` (`…`, Cmd+Shift+J: shows / hides the files to include / exclude, focusing the Search view first from elsewhere); `NextInput` / `PreviousInput` (Tab / Shift+Tab: `SearchView::cycle`); `Refresh` (Enter) searches now; `FocusEditor` (Esc) back to the editor when there's a tab, results kept), `search_key` / `search_paste` (edit the focused input — `search_view.input`: query, include or exclude; from the list, the one that last had the keys; edits schedule a debounced restart; emptying the query searches — i.e. clears — at once; the replace input's edits search nothing, they only redraw and `refresh_replace_previews`), `find_in_folder` (`explorer.findInFolder`: the selected explorer folder as `path_filter::folder_pattern` in the include input, details shown, the query focused and selected, searched now; a file: a message), `search_tick(now)` (the event loop's deadline branch and `settle`: runs a due restart), `run_search` (the view's query → `start_search`, error into `search_view.error`), `search_click(m, count)` (toggle buttons and the `…` details button from `hits.search`; an input's rect gives it the keys; a result row by its key: the list takes the keys and selects it, a match row opens with the focus staying in the list, a double click (also on a file row: its first match) opens and focuses the editor; else the input takes the keys), `search_scroll(delta, m)` (wheel; the hover moves to the row now under the pointer), `search_hover` (mouse moves: `search_view.hover`). Opening a result (click, Enter, F4) goes through `open_search_target`: while `search_view.previewing()` it's `open_replace_preview(target, focus)` — a `Pair::REPLACE` diff tab of the file in the active group (the group's one for that file reused) with `Results::file_replace` as its `DiffTab::replace` (`set_replace`: reloads), the cursor on the result's line, the focus left where it was unless `focus`; `refresh_replace_previews` gives every open preview the new replace after a replace edit, a toggle, a new search or a dismissal (a dismissed file's replaces nothing; not while the input is empty). Sessions skip these tabs (`session::Side: TryFrom<Text>` fails for `Text::Replaced`). A click on a row's `×` dismisses it (`search_dismiss`; an emptied list gives the keys back to the query), on a file row's chevron collapses / expands it (and selects it). The results list (`search_view.list_focused`, `Context::SearchResults`): `FocusResults` (Down in the query: the list, keeping its selection or selecting the first row), `Up`/`Down`/`PageUp`/`PageDown`/`First`/`Last` (Up from the first row hands the keys back to the query), `Open` (Enter: the selected match, or a file row's first, opened via `open_result` with the editor focused); `NextResult`/`PreviousResult` (F4 / Shift+F4, global: `SearchView::step`, opened without moving the focus; nothing without results); `Collapse` / `Expand` (Left / Right), `Dismiss` (Delete), `CollapseAll` / `ExpandAll` (palette), `ReplaceOne` (Cmd+Shift+1 / Linux Ctrl+Shift+1 in the list: the selected row's `replace_scope`) and `ReplaceAll` (Cmd+Alt+Enter / Ctrl+Alt+Enter in the inputs and the list) → `app/replace.rs`; a click on a hovered row's `⇄` selects it and replaces it, on `⇄ All` runs `ReplaceAll`. A finished search with no files hands the keys back to the query (`search_results`). In the list a typed character goes back to the query and types there (paste too); other unbound keys do nothing. `open_result(target, focus)` joins the root and opens with `Goto::Match` in the active group — the last focused one while the side panel has the keys. Also `start_search(Query)` (drops the running search's `Handle`, which cancels it; bumps `search_generation`; collects rope snapshots of dirty buffers inside the root; empty pattern → finished empty `Results` without spawning; invalid regex or glob (`workspace_search::filter`) → `search = None` and the `SearchError`; the query's include / exclude go to the job as its `filter`) and `search_results(batch)` (`AppEvent::SearchResults`: `Results::add` drops stale generations; the handle is released when done). `app.search` is what `ui::search` draws.
- `syntax.rs` — language detection for buffers (`detect_language`: the buffer's `language_override` ("Change Language Mode": `change_language_mode` opens `Picker::Language`, `language_rows`, `language_picked` sets the override and the language), else associations / name / first line; `add_buffer` sets it, `redetect_languages` after an explorer rename or a `.workspace` change to `[files] associations`, `load_associations` compiles them in `new` and on reload, reporting bad entries) and `sync_syntax` (every buffer's `Syntax::update` with `settings.syntax_max_bytes`; spawns the `ParseJob` it returns → `AppEvent::Parsed { buffer, parsed }` → `parsed`), `load_grammars` (from `start`) / `rebuild_grammars` ("Languages: Rebuild Syntax Plugins", `languages.rebuildSyntaxPlugins`, unbound; refused with a message while a job runs) → `grammar_job(force)`: marks each of `app.syntax_plugins` (empty by default; `main` sets every registered plugin, tests their own) `Waiting` in `app.grammars` (the Tools view's rows) and runs ONE `spawn_blocking` that, per plugin, sends `AppEvent::GrammarBuilding` (`grammar_building`: row `Building`, its log cleared), runs `syntax::build::build` when it has `src/parser.c`, then `PluginId::load` (skipped after a failed build), and sends `AppEvent::Grammar { language, build, replaced_in_use, result }`. `grammar_loaded` pushes the build's log lines to `Tool::Grammar(id)`; Ok: row `Ready`, that language's `Off` buffers go `Wanted` (a forced rebuild of a grammar already in use says the new build is used from the next start); Err: the error to the log at Error (the row's badge), row `Failed`, `notify(Error, "Syntax plugin <id>: …")`; diff tabs already open aren't re-highlighted. `sync_syntax` runs once per event-loop turn before drawing, in `start`, and in the test helpers `pump`/`settle`; without a tokio runtime it does nothing.
- `lsp.rs` — `sync_servers` (each loop turn, `start`, `pump` / `settle`; nothing before `lsp.started()`; when `servers_dirty` — set by `add_buffer`, `redetect_languages`, `decide_trust`, `config_loaded` — hands the open buffers' languages, `.workspace` and `trust` to `lsp::Manager::sync`; then always `lsp.sync_documents(&mut buffers)`: opens / closes / updates documents, so renames, language changes and closed tabs need no hook), `save_done` calls `lsp.saved(buffers, id)` (`didSave`), `lsp_event` (`AppEvent::Lsp`: `Event::Diagnostics` → `Manager::publish` (into the store and the file's buffer; `diagnostics_changed` for the lightbulb); `Event::ServerRequest` → `server_request` (`app/code_action.rs`); anything else → `Manager::handle` → `notify`; then, as after `sync_servers`, `drop_cleared_diagnostics`: marks of servers the manager dropped are cleared from every buffer), `add_buffer` places stored diagnostics (`lsp.load_diagnostics`), `shutdown_servers` (async; tests after `Quit`; `run` quits through `tasks.rs`'s `shutdown`). Requests: `Request` (`Hover { word }`: `Some` = the mouse's run; `Definition { word }`; `Completion { generation }`: current while `completion.ask` has that generation and the cursor stays in its word, edits or not; `Resolve { generation, index, accepted }`: current while that list is shown, or with `accepted` while the buffer is at that revision; `References { word }`, `PrepareRename { word }`, `Rename { old, new }`, `Format`: current like hover / definition; `CodeActions { purpose, range }`: each purpose its own kind (`same_kind`), the hover's current while its popup is, the others like hover; `ResolveAction`; `ExecuteCommand { title }`: always current), `Pending` (with the `server` it went to), `Pending`, `send_request` / `send_request_with(…, extra)` (cancels a pending one of the same kind, then `lsp.request_at`; false when no server takes it), `send_doc_request` (no position: formatting), `send_server_request` (params as given: resolve), `cancel_requests(which)`, `check_requests` (end of `handle_event`: cancels pending requests whose buffer was edited or whose cursor / pointer moved — `request_current`), `answer` (`Event::Response` by (server, id): stale → dropped; a routine error (`RpcError::is_routine`: cancelled, ContentModified) → dropped quietly, a completion's `ask` cleared; other errors → dropped (a definition error says "No definition found", a references error "No references found for 'w'", a prepareRename error its message, a rename error "Rename failed: …"), else `hover_answer` / `definition_answer` / `completion_answer` / `resolve_answer` / `references_answer` / `prepare_rename_answer` / `rename_answer` / `format_answer` (an error: "Format Document failed: …"); a completion error to Ctrl+Space says "No suggestions."); `Failed` / `Exited` drop the server's pending requests.
- `indentation.rs` — the active buffer's indentation: `indentation_clicked` (`Hit::StatusIndentation` → `Picker::Indentation`), `indentation_command` ("Indent Using Spaces / Tabs", "Change Tab Display Size" → `Picker::IndentSize { buffer, kind }`; "Detect Indentation from Content" → `indentation::guess` of the text now + `Buffer::redetect`; with `detect_indentation = false` the guess is kept as the chosen indentation, since `for_buffer` ignores guesses then), `indent_size_rows` (the picker's rows: current = the size in use, configured = the settings'; it starts on the current one), `indent_size_picked` (`Buffer::choose_indentation` or `tab_display`, from accepting `Action::IndentSize`), `convert_indentation(spaces)` ("Convert Indentation to Spaces / Tabs": `indentation::convert` at the buffer's tab width, then `Buffer::indentation` = spaces of its indent size / tabs of its tab width, `tab_display` kept; gated by `active_writable`, so nothing on log and commit tabs).
