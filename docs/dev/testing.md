# Test helpers by feature (detail)

How to drive and inspect each feature in end-to-end tests, moved out of the root `CLAUDE.md` (which keeps the general harness: building the app, input, `settle` / `pump`, rendering). Read the ones for the area you test; add new helpers here, not to the root file.

- Files changed on disk: write / remove / rename the file with `std::fs` and `settle` on the buffer (`rope`, `deleted`, `disk_conflict`, `is_dirty()`); `app.disk.checked` / `app.disk.reloads` count finished checks and reloads, `app.disk.busy(id)` (a check running or wanted) — e.g. wait for `checked` to grow after a save to see its own events found nothing. The banner's buttons: `app.hits.groups[i].banner` after a draw (`milestone10_tests`).
- State: `app.active_buffer()`, `app.group()`, `app.groups`, `app.prompt`, `app.ui.focus`, `app.explorer.rows()`, `app.quitting()`, `app.search` (workspace search `Results`; start one with `app.start_search(Query)`, or through the Search view: Cmd+Shift+F, `type_text`; then `settle` until `done`), `app.search_view` (`selected_row(results)`, `list_focused`, `target(results)`); `app.test_search_batch(batch)` takes in a `workspace_search::Batch` as if the running search sent it (to test streaming). `app.test_lsp_event(event)` takes in an `lsp::Event` the same way, before the turn's `sync_servers` (a publish arriving in the same turn as an unsent key). References / rename: F2's prompt is `Prompt::Input` with `InputKind::RenameSymbol` (`i.field.text`, `all_selected`); `FakeOptions::no_prepare_rename`; script `textDocument/prepareRename` / `textDocument/rename` / `textDocument/references` with `fake.respond` (unscripted ones fail with MethodNotFound: the error path); `milestone9_tests::{doc_edit, text_edit, rename_prompt}`. Hover / definition: `app.hover` (`popup`, `rest`), `app.hits.hover` (the popup's rect after a draw), `app.test_hover_tick(now)` fires the mouse rest timer without sleeping (`Instant::now() + hover::DELAY`); diagnostics in hover (`fixes_tests`): `fixes_app` (squiggles on a word, whitespace, a line end and an empty line), `rest(app, term, cell)` (draw, move, fire the timer; false when nothing there to hover), `rows` (the popup's rows, rules as `---`), `FakeOptions::no_hover`, `milestone9_tests`' helpers (`popup_rows`, `publish`, `diag`, `open_synced`, …) are `pub(crate)`; `app.pending_requests()` lists (kind, position) of pending requests, `app.locations` (`app.test_locations_read(generation, files)` takes in a background preview read); with the fake, `fake.respond` / `fake.hold` script answers and `fake.requests(method)` / `fake.cancelled()` show what arrived (wait with `settle` before reading them: the fake runs on another task). `Buffer::from_str` exists for unit tests.
- Git: make temp repos with `git::test_repo` (`init` = `git init -b main`, `commit_all`, `git(dir, args)`, `git_with_input` for `git add -p`'s answers); keep the trust store outside the repo (`milestone10_tests::dirs`: `proj/` + `state/`) or it shows as untracked. `app.git.status` (`Option<git::Status>`), `app.git.running()` (a refresh running or queued); wait with `milestone10_tests::settle_git(app, |status| …)`. Gutter markers: `buf.quick_diff` (`marks()`, `running()`, `want(revision)`), `app.quick_diff` (`peek`, `staging` (tasks running), `deadline()`); inline blame: `app.blame.on`, `buf.blame` (`running()`, `want(revision)`, `hunks()`), wait with `todo_tests::inline_blame::settle_blame` (`settle` fires `blame::DELAY` itself); `milestone10_tests::{dirs, open_file_app, settle_git}` are `pub(crate)` for other test files; `settle` runs `sync_quick_diff` and fires the delay itself; `milestone10_tests::{settle_markers, markers (drawn: line, glyph, colour), run_command (a palette command by title), copy_repo (for `git add -p` / `reset -p` to compare with), index_state}`; the peek's buttons are `app.hits.quick_diff` after a draw; the marker column is `text.x - 1` of the group's `GroupHit`. Diff tabs: `app.open_diff(path, Pair)` (what Open Changes and the Source Control list call), `app.group().active_diff()` (`doc`, `cursor`, `top`, `rows()`, `aligned().starts`, `hunk_at_cursor()`), `app.diffs_settled()` (every diff tab loaded and current, no stage or git refresh running; `milestone10_tests::settle_diffs` adds the status read), `app.diffs.staging` / `deadline()`, `app.hits.group(g).diff` (rows rect, Stage buttons by hunk) after a draw, `app.test_execute(cmd)` runs any `Command` as its key would (`milestone10_tests::milestone_10_editor_commands_on_a_diff_tab_do_nothing` runs all of them); `milestone10_tests::{draw_sized, find_text, bg}` read cells. Explorer colours / the branch: draw and read cells (`explorer_row`, `status_bar`). The Source Control view: `app.scm` (`rows(status)`, `selected(rows)`, `select_key`), `app.hits.scm` after a draw; `milestone10_tests::{ctrl_shift_g, scm_rows (each drawn row's words, buttons left out), side_text, scm_row (a row's cell by key), scm_button (moves the pointer over the row, draws, returns its button's cell), selected_key, settle_stage (stage tasks done and the status read), scm_repo}`.
- Git history (`git_history_tests`): `app.git_history` (`path`, `commits`, `more`, `loading`, `error`, `generation`, `stale`, `selected()` / `selected_row()`, `scroll()`, `collapsed()`, `focused()`); draw for `app.hits.history` (`divider`, `header`, `list`, `top`) and `app.hits.history_scrollbar`; wait with a local `settle_history`-style condition (`!app.git.running() && path && !loading && commits.len() == n`) or on `app.git.status.head_id` after a commit outside jed; `app.test_git_history_page(path, skip, generation, result)` takes in a page as the background read sends it (to test that stale ones are dropped); `milestone10_tests::{dirs, open_file_app}` build the app, `app.open_diff(path, Pair::UNSTAGED)` + `app.diffs_settled()` put a diff tab on screen. Commit tabs: focus the section directly (a click on a row opens the commit) with `ui.focus = Focus::SidePanel`, `ui.side_panel = Explorer`, `app.git_history.set_focused(true)`, then Down / Enter; wait for `app.active_commit().is_some_and(|c| c.show.is_some())` (`app.commit_in(group)` for another group), draw for the text width (`hits.group(g).text`), and read the buffer's text / `c.file_row(k)` / `c.own_file_row()` / the view's cursor (`git_history_tests::{text_width, cursor_line, doc_start, tab_commit}`); `app.clipboard.read()` after Cmd+C; sessions build the app with `app.state_dir = Some(...)` before `test_start` (`git_history_tests::{open_state_app, quit, commits_loaded}`, `enter_commit` (focus, Enter, waits), `focus_history` (the section's keys without a click), `commit_lines` (the active commit buffer's lines), `two_commits` / `wide_commit` (a stat whose layout depends on the width), `cli_show` (the same `git show` output), `click_history_row` / `click_commit_row` (a drawn row's click), `diff_changes` (a side-by-side diff's removed / added line texts) and `cli_diff` (the same lines from `git diff`). The Done-when walk is `git_history_done_when`.
- File history: `app.file_history` (`running()`, `done`: history tasks — a save's snapshot, a rename's move — in flight / finished); read what was recorded with `history::entries` / `history::read` (`milestone11_tests::{save (Cmd+S, waits for the save and its history task), snapshots}`); `app.file_history.picker` (the picker's entries), `app.file_history.restoring` (restores reading their entry; `milestone11_tests::{open_history (runs Show / Restore through the palette, waits for the picker, returns its labels), settle_restore, two_entries, history_not_open, explorer_with_src, right_click_row}`; right-clicks: `app.mouse(MouseEventKind::Down(MouseButton::Right), x, y)` on a drawn tab (`app.hits.groups[0].tabs`) or explorer row (`app.hits.explorer_rows`)); `app.fs_flushed` (`cfg(test)`) lists every path `flush_fs_changes` handled (watcher filtering).
- Tasks: set `app.tasks.user` (from `tasks::templates::load`, its errors through `app.report_errors`, as `main`) before `test_start` (`milestone12_tests::open_app`); `app.task_templates()`, `app.run_task(name)` → `RunId` (or through the picker: `milestone12_tests::{open_run_task, pick_task}`), then `milestone12_tests::settle_ended` (ended and its end note written — the app appends it when it handles `Ended`, so wait for that, not just the status) and read `run.screen().screen()` (`contents()`, `cell(row, col)` colours / bold); draw once before running when the screen size matters (a run takes its size from the last frame); task tabs: `app.ui.panel_tab` (`PanelTab::Task(id)`), `app.hits.panel_tabs` / `panel_closes` after a draw, `milestone12_tests::{task_tabs, find, fg, bg}`; keys go to the focused tab's task (`app.press`, `Event::Paste`); don't hold the screen guard across an `.await`. Real PTY runs through `$SHELL` (`Tasks::shell`; unit tests use `/bin/sh`); a command that must ignore SIGHUP should print a line after its `trap` and the test wait for it. What a terminal shows is checked against `milestone12_tests::reference` (an independent model of a terminal: text, CR / LF, `ESC[K`, cursor moves, SGR colours, OSC (cargo's hyperlinks) shown as nothing; panics on anything else) fed the same command's piped output, via `assert_drawn_as` (the drawn task area, text and themed colours, row by row); `settle_ended_within` waits longer than `settle` (a real build). `milestone12_tests::{open_app, dirs, settle_ended}` are `pub(crate)`. Cursor shape: `app.sync_cursor_shape(&mut Vec<u8>)` returns what `run` would send (`todo_tests::cursor_style::sent`). A test running `cargo` gives each build its own `CARGO_TARGET_DIR` and `CARGO_HOME`, pins the environment variables that change what cargo prints (`RUSTFLAGS`, `CARGO_TERM_*`) and never builds one crate twice at once (lock messages change the output), and skips with a note without `cargo`. Check nothing is left with `libc::kill(-pgid, 0)` on `run.pid()` (the process group); quit = `test_execute(Command::Quit)` + `app.shutdown().await`, as `run` does; dropping the app kills its runs.
- Sessions: set `app.state_dir = Some(tempdir)` before `test_start`, then `settle(|a| !a.session.loading())` (the restore's read) — `app.session.restored` counts applied restores; quit as `run` does (`test_execute(Command::Quit)` + `app.shutdown().await`, which writes it) and build a new `App` on the same root and state dir; `session::file` / `load` / `save` read or plant session files (`milestone13_tests::{dirs, start (no wait), reopen (waits), quit, layout (each group's tabs: text tabs' selections / primary / scroll, diff tabs' pairs), set_view}`).
- Crash backups: with `app.state_dir` set, `app.test_backup_tick(after)` fires the backup timer `after` from now (after a `sync_backups`, which sets the deadline; `backup::INTERVAL` writes what's due, less does nothing) — wait with `settle(|a| !a.backups.busy())` (a job or the start's scan running); `drop(app)` without `shutdown` is a kill; `app.shutdown()` without `Quit` is the terminal going away; `app.test_panic_backup()` runs the panic hook's backup (the crash snapshot, then `panic::back_up_dirty`: a global, one test only); `start` without `settle` leaves the start's scan unhandled (`busy()`). `backup::file` / `read` / `write` / `list` inspect or plant backups; the offer is `Prompt::RestoreBackups` (`app.backups.offered`), restores done when `app.backups.restoring() == 0`; `app.backups.jobs_done` counts jobs (`milestone13_tests::{back_up, offered, backup_file, buf_of, text_of}`).
- Tool logs (`tools_tests`): set `app.logs` (as `main`) and `app.state_dir` before `test_start` (`tools_tests::open_app`); read rings with `app.logs.texts(&tool)` / `lines(&tool)` (`Tool::Server("clangd".into())`, `Tool::Jed`), `settle` until a line arrives; the fake's `test/stderr` (`{ "text" }`), `test/log` / `test/show` (a `logMessage` / `showMessage`'s params) and `test/crash` feed it; `tools_tests::flush` waits for the disk (`Logs::flush` in `spawn_blocking`) before reading `<state>/logs/tools/<name>.log`. The Tools view: `tools_tests::{tools_app (`pub(crate)`, as is `run_ended`) (a fake clangd's `a.cpp`, the user's tasks `ok` (`true`) / `bad` (`exit 3`), a 40-column side panel), with_clangd, run_ended, tools_rows (draws, each drawn row's text), cell_of (a row's cell by key and text: colours)}`, `app.tools_rows()`, `app.tools_view` (`selected_key()`, `selected_row(rows)`, `scroll(rows)`), `app.hits.tools` after a draw; `app.test_take_redraw()` (whether something asked for a redraw since the last call); its scroll bar through `todo_tests::side_scroll_bars::{List, drag_the_bar}` (pub(crate)).
