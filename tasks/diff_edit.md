See [Git](../PLAN.md#git-view-and-stage-only). Diff tabs are read-only today: a row cursor, Stage / Unstage / Revert buttons and next / previous change. Give them the editor's caret, text selection and editing, with every edit going to the file's ordinary working-tree buffer — never to a historical side, the index or HEAD, and never to a temporary file.

  - A caret and selection in either side of a diff tab, in that side's own text (a line and a byte into its `Lines`), one side active at a time: a click sets the side and the caret there, a drag / Shift+click extends, double / triple click select a word / line as in the editor; Up / Down / Page / Home / End and Cmd+Left / Right / Up / Down move and Shift extends, all the editor's movement keys. The row cursor (`DiffTab::cursor`, `cursor_line`, `hunk_at_cursor`, the buttons) stays the caret's row. Drawn with `editor.selection` and the terminal cursor on the active side, over the diff backgrounds and under the syntax colours; the wheel, scroll bars, next / previous change and marks are unchanged.
  - Cmd+C (and Cmd+X on an editable side) copy the selection from either side's `Lines`; Cmd+A selects the active side; Esc clears. A selection stays in one side; a drag past the divider stops at it.
  - The editable side is the right one when it is the file's current text: `Text::WorkTree` for unstaged changes, `Text::Buffer` for the changed-on-disk Show Diff, a history compare and a compare-files tab. `Head`, `Index`, `Disk`, `History`, `Commit`, `Empty`, `Replaced`, `ConflictCurrent` / `ConflictIncoming` and every left side are read-only: they select and copy, but a key there says the side is read-only. A history compare therefore edits the worktree file on its right side; the snapshot on its left is never written, and no temporary file stands in for a history or commit side.
  - Editing is the editor's: the diff-side caret / selection becomes a scratch `View`'s `Selections` at the same bytes of the file's buffer, and `edit::run` handles the key (typing, Enter, Tab, Backspace / Delete, paste, cut, undo / redo), through `Buffer::edit` with the usual undo grouping and a dirty buffer. The buffer's text tab, if any, follows through `follow_edits`; Cmd+S saves the worktree file as from any diff tab; auto-indent, auto-close and the buffer's settings apply. A read-only buffer refuses as a text tab does.
  - A diff of a file that isn't open: the first edit opens the file's text tab and puts the diff back in front (the diff stays active), then applies the key; the same buffer is then the diff's live side. An open file in another group is reused, not reopened.
  - The diff is re-read `diff_view::DELAY` after the edit and keeps the caret / selection on the same text, as `DiffTab::finish` keeps the cursor's line today; the caret stays on the editable side.
  - Stage / Unstage / Revert from a diff still work; where [Selected lines in diff tabs](diff_tab_selected_lines.md) lands, its row range is the lines each selection touches.
  - [Compare any two files or buffers](compare_files.md) generalises the editable side: in its tabs either side that is an open buffer is editable, so keep the editable side a per-tab value rather than "the right one"
  - Deferred: multi-cursor, find, completion / hover / diagnostics / blame in diff tabs, editing the read-only sides, and keeping a diff tab's caret / selection in sessions (a restored diff opens at its first change, as now). The `Context::Diff` bindings are the editor's already; no new keys, so `docs/terminals/` is untouched.
  - Needs: `DiffTab` / `Doc` / `Lines` / `Text` (`diff_view.rs`), `ui/diff.rs`, `app/diff_view.rs`'s `diff_command` / `diff_mouse` and `execute`'s routing, `edit::run` / `Buffer::edit` / `Selections` / `pos`, `active_file_buffer` / `open_file` / `Buffers`, `follow_edits` / `sync_diffs`.
  - Done when: in an unstaged diff, clicking / dragging either side selects text, drawn across the rows; Cmd+C copies exactly the selected text, Shift+arrows extend, Cmd+A selects the side and Esc clears; typing / Enter / Tab / Backspace / Delete / paste on the right side edits the open file's buffer as one unsaved edit the editor's undo / redo and Cmd+S see, and the diff re-aligns with the caret kept; a history compare's right side edits the working-tree file and its history side is unchanged (nothing under `.jed/history/` is written); a commit, staged and conflict diff says the side is read-only and edits nothing; a file not open opens behind the diff on the first key and the key lands; a read-only buffer refuses.
