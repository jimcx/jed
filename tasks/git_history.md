  - Needs: `git2` and the diff view (M10), side panel lists and their scroll bars, sessions (M13)
  - The Explorer view split vertically: the tree above, "Git History" for the active file below (header, collapsible, draggable divider); commits read off-thread in pages, refreshed when HEAD moves
  - Commit tabs: read-only text tabs holding `git show --stat`, with git's colours; clicking a file opens its diff (parent ↔ commit) in the group to the right
  - Done when: in a repository with a few commits touching a file, opening that file lists its commits newest first in the Explorer view's lower section (and switching tabs switches the list); clicking a commit opens a tab whose text matches `git show --stat --format=medium <commit>` at the tab's width (a test compares them line by line, colours by line kind); clicking a file row there opens a side-by-side diff of that file's change to the right, matching `git diff <commit>^ <commit> -- <file>`; a new commit made outside jed appears at the top; quit and reopen restores the tabs
  - Tasks (one agent and one commit each):
    - ✅ git_history-a: the model, no UI: `git::log` (a path's commits from HEAD, git's default simplification, paged, off-thread job), `git::show` (a commit's header, message and per-file stat: insertions / deletions, binary sizes, renames with git's default detection, first parent / root) and `git_show::render(show, width)` → lines with kinds (git's `--stat` graph scaling); `diff_view::Text::Commit` (a blob from a commit's tree); unit tests against the `git` CLI's own output on test repositories
      - `git::log::commits(repo, path, skip, limit)` → `Page { commits, more }`, git's `try_to_simplify_commit` (prune + simplify_history): TREESAME to a parent hides the commit and walks only that parent (a merge: its first TREESAME parent), root iff the path is in its tree; committer-date order, `PAGE` 200, stops one commit past the page; `Commit { id, short, summary, author, time }`
      - `git::show::read` → `Show { id, parents, author, email, time + offset, message, files }`; stat against the first parent (root: empty tree; merge: first parent — what `git show --stat` prints, git 2.53), `find_similar` at git's 50% threshold, binary sizes, mode-only changes
      - `git_show::render(show, width)` → `Vec<Line>` of kinded segments exactly as `git show --stat --format=medium --stat-width=width` (git's date format, message indent, `pprint_rename` brace form, `show_stats` number/graph scaling and summary rules)
      - `diff_view::Text::{Commit(Oid), Empty}` and `Pair::commit(commit, parent)` (root: `Empty`), titled `name (abc7hex)`; `session::Side::{Commit, Empty}` round-trip
      - Deferred: non-UTF-8 paths aren't C-quoted and `.gitattributes` binary attributes / diff drivers aren't consulted (documented in `git_show.rs`); a commit message's first paragraph isn't folded as `%s` does (the list shows the first line)
    - ✅ git_history-b: the Explorer view split: the "Git History" section (header, collapse, draggable divider, `Scrollable` list, the active file followed, pages read as it scrolls, refreshed when HEAD moves, "No history"), theme keys; no commit tab yet (Enter does nothing)
      - The Explorer body splits into the tree and a bottom section (divider, `GIT HISTORY` header, rows), `GitHistory` in `git_history.rs` (model: commits, `more`, loading/error/generation/stale, collapse/focus, selection by commit id, scroll, section height); the divider drags (`Hit::HistoryDivider`), the header toggles, rows follow `active_path` (a diff tab counts as its file)
      - `app/git_history.rs`: `sync_git_history` in every turn (`start`, `run`, `pump`/`settle`), `git::log::commits` in `spawn_blocking` one page at a time (PAGE 200, next page near the drawn end), stale paths/generations dropped; `git::Status::head_id` compared in `git_refreshed` reloads page 1 only when HEAD moves (selection kept by id, top only when the first commit changed)
      - `Command::GitHistory` / `Context::GitHistory` (Up/Down/PageUp/PageDown/Home/End, Left/Esc back to the tree); a click selects and focuses the section; the wheel and its own bar (`ScrollTarget::History`) scroll it; rows show summary, author, relative date and short id (`gitHistory.author` / `.date` / `.hash`); "Reading history…", the error, "No history"
      - Deferred: no keyboard collapse toggle (header click only); a failed page 2 isn't retried until HEAD moves; Enter does nothing (git_history-c opens the commit)
    - ✅ git_history-c: commit tabs (read-only commit buffers in text tabs — first built as a `Tab::Commit` with its own cursor and drawing, then moved onto the editor after review — with git's colours, reuse per commit, splits) opened from the section, and stat rows opening the file's diff in the group to the right (split when none, reused); sessions keep both and the section's layout
      - `CommitTab` (`commit_view.rs`): the rendered `git_show` lines for the drawn width, a read-only text cursor and selection (Up/Down/Page, Home/End, Cmd/Ctrl+Home/End, Left/Right, word keys, Shift extends, Cmd+A, Esc), Cmd+C copies the selection or the cursor line, its own scroll bar; splits share the loaded `Show`/lines
      - `ui/commit.rs`: segments in `gitShow.commit` (yellow) / `gitShow.add` (green) / `gitShow.del` (red), the file whose history opened it highlighted (`editor.lineHighlight`), selection in `editor.selection`, terminal cursor when focused
      - `app/commit_tabs.rs`: `sync_commit_tabs` loads each commit in `spawn_blocking` (`CommitLoaded`, routed by commit id), `open_commit` reuses a tab for the commit anywhere, `GitHistoryCommand::Open` (Enter) and a click on a history row open it; `Context::Commit` (parent Editor) + `CommitCommand::Open` (Enter) open the stat row under the cursor; `open_commit_diff` uses the group to the right (splitting an empty group when none) and reuses its commit-diff tab for the next file (`Pair::commit(commit, first_parent)`, no Stage/Revert)
      - Sessions: `TabState::Commit { commit }`; commit tabs and commit diff tabs are dropped when the repository has no such commit; `SideState` gained `history_collapsed` / `history_height` (serde defaults, `VERSION` stays 1)
      - Deferred: a restored commit tab has no `file`, so its stat-row highlight comes back only when reopened from the section; before the first frame a stat row's diff falls back to the next group in reading order (with a drawn frame it is the group strictly to the right, else split right)
    - ✅ git_history-d: the done-when tests (against the `git` CLI), gaps and hand checks; marks the milestone ✅
      - `git_history_done_when` walks the plan's scenario against the CLI: four commits, the section lists `git log -- a.txt` newest first, switching tabs switches the list; a click on a history row opens the commit; its text matches `git show --stat --format=medium --stat-width=<drawn width>` line by line (drawn cells too) with `gitShow.commit` / `.add` / `.del` colours and the own file's row highlighted; a stat-row click opens the side-by-side diff in the group to the right, its changed lines matching `git diff <commit>^ <commit> -- a.txt`, no Stage/Revert buttons; a CLI commit outside jed appears at the top; quit/reopen restores the commit tab, the commit diff tab and the section's collapsed state and height
      - Supporting tests: the commit text at two widths, root / deleted / binary stat-row diffs, read-only (no writes, no messages), Enter with nothing selected, and the geometry fallbacks (a group below isn't reused; no frame → reading order / split right)
      - Fixes: the stat row's group comes from the drawn geometry (strictly to the right; split right when none); Enter with nothing selected opens the first commit
  - Deferred: non-UTF-8 paths are shown lossily, not C-quoted (`core.quotePath`), and non-UTF-8 author / message bytes are lossy (a commit's `encoding` header isn't honoured); `.gitattributes` binary attributes, diff drivers and textconv aren't applied (a text file marked `binary` shows `| 0` where git prints `Bin old -> new bytes`); the history row shows only the message's first line (git's `%s` folds the first paragraph); a rename's stat row opens its new path on both sides — the whole file added, not the rename `git diff <commit>^ <commit> -- <newpath>` would show — and a commit that renamed the file away doesn't highlight its row; commit tabs don't scroll horizontally (lines are cut at the tab width and the cursor clamps at the right edge); while a commit tab is active the section says "No history" (it follows a file; rows return on the file's or its diff's tab); a restored commit tab has no `file` (its row highlight returns when reopened from the section); the section collapses only by clicking its header (no keyboard toggle); a failed later page is silent and isn't retried until the file or HEAD changes; before the first frame a stat row's diff falls back to reading order
  - Still to check by hand: in a real terminal (kitty / a legacy one / macOS), a repo with a merge, a rename, a root commit, a binary file and a deletion — each commit tab against `git show --stat --format=medium` (colours, author date and offset, message indent, graph scaling) and each stat row's diff against `git diff <commit>^ <commit> -- <file>`, by Enter and by mouse, with no Stage/Revert; section row click, divider drag, header collapse, wheel and the section's own bar; resizing narrow / wide re-renders the stat at the new width and cuts long lines; a commit / checkout / reset outside jed refreshes the list (selection kept, the top follows a new first commit); quit and reopen with a commit tab, its diff tab and a collapsed / dragged section, then reset + gc a restored commit and reopen (its tabs dropped); a history over 200 commits paging as it scrolls; non-ASCII paths and encoded messages (the known losses above); Cmd+C / document ends on macOS
