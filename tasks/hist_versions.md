---
id: hist_versions
name: Open and restore earlier versions of a file
summary: a file's earlier version — a saved snapshot, or its blob at a commit — opens as a read-only text tab so its text can be selected, copied and searched, and the lines a selection touches restore into the file's buffer as one undo step.
status: open
priority: 0
dependencies: []
---

  - Opening a version: "File History: Open" for an entry (a second action beside Compare in the picker and the Explorer's File History section), and a commit's file ("Open File", a second action on a commit tab's stat row and a commit diff tab) open a read-only buffer holding the version's bytes — `history::read_snapshot` for a snapshot, the blob read behind `Text::Commit` for a commit, extracted to a shared helper — titled `a.rs (History: 3 min ago)` / `a.rs (abc1234)`, highlighted by the file's language. The buffer is read-only with no file (as `Buffer::log` / `Buffer::commit` are, through `without_file`), so copy, find, select all, scrolling and splits work and nothing keyed by a path (saves, git, servers, backups) touches it; a version whose entry or commit is gone reports and doesn't open.
  - Selecting and copying is the read-only editor's; the tab is the first place a snapshot's whole text (not only its diff) or a commit's file content (not only the stat) can be selected and copied.
  - Restore selected lines: "File History: Restore Selection" (palette, unbound; a key in the File History section, Cmd+Enter / Ctrl+Enter — decide): the lines each selection touches in the version tab put the version's lines back into the file's buffer as one undo step, the rest of the file left alone. The version's lines for the span replace the buffer's, mapped through the version↔buffer diff so a file edited since the version still restores the right lines (`disk::changes` / `diff_view::revert_edit` as the line→edit model); one `EditKind::Other` step through `Buffer::edit`, nothing written until saved. A file not open opens first, then restores; a read-only buffer is refused. A compare diff tab (history or commit) restores the same way once the [Selected lines in diff tabs](diff_tab_selected_lines.md) row selection exists.
  - Needs: `history::read_snapshot` / `history::entries`, the diff view's `Text::Commit` blob read, the read-only buffer factories (`Buffer::log` / `Buffer::commit` / `without_file`), `disk::changes`, the history picker and the Explorer's File / Git History sections, `diff_view::revert_edit`.
  - Done when: "File History: Open" opens the snapshot's bytes as a highlighted read-only tab whose text can be selected and copied, and survives a split and a session (reopened from its snapshot); a commit's file opens the same way from its stat row and a commit diff; restoring a selection of lines from the version tab puts exactly those lines back as one undo step, the rest of the buffer unchanged and undo removing it; a file not open opens first and a read-only buffer refuses.
